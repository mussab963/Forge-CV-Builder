CVForge
CVForge is a modern resume builder built with Vue 3.
It helps users create, customize, and export professional resumes directly from the browser without requiring an account or backend.
Features
- Multiple resume templates
- ATS-friendly and creative layouts
- English and Arabic support
- Local auto-save
- Resume tips and writing guidance
- Light and dark mode
- A4 preview
- PDF export
- No login required
Getting Started
cd frontend
npm install
npm run dev
Build
cd frontend
npm run build
Deployment
The project is ready to deploy on Netlify.
Netlify will use the configuration included in the repository and build the frontend automatically.
Tech Stack
- Vue 3
- Vite
- JavaScript
- CSS
- Local Storage
Privacy
CVForge stores resume data locally in the browser.
No personal data is sent to a server.
